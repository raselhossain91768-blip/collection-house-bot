# Collection House – AI Facebook Messenger Bot & Order Manager 🚀

**Collection House** (https://collectionhouse.com.bd/) এর জন্য তৈরি করা একটি ফুল-ফিচার্ড এআই মেসেঞ্জার বট ও অর্ডার ম্যানেজমেন্ট সিস্টেম।

---

## 🌟 প্রধান সুবিধাসমূহ (Key Features)

1. **স্মার্ট এআই চ্যাট ও সেলস ক্লোজিং:**
   - বাংলা ও বাংলিশে কাস্টমারের সাথে মানুষের মতো প্রফেশনাল কথোপকথন।
   - SUS 316 হনিকম্ব কড়াই, এয়ারটাইট গ্লাস জার, অয়েল স্প্রেয়ার ইত্যাদি প্রোডাক্টের নিখুঁত বিবরণ ও মূল্য প্রদান।
   - ডেলিভারি চার্জ (ঢাকার ভেতরে ৮০৳ / বাইরে ১৫০৳) এবং ক্যাশ অন ডেলিভারি নিয়ম স্বয়ংক্রিয়ভাবে বুঝিয়ে বলা।

2. **স্বয়ংক্রিয় অর্ডার ডিটেকশন ও সেভিং (Auto Order Capture):**
   - কাস্টমার যখনই তার **নাম, মোবাইল নম্বর এবং ঠিকানা** দেবে, এআই তা স্বয়ংক্রিয়ভাবে ডাটাবেজে নতুন অর্ডার হিসেবে সেভ করে নেবে।
   - কাস্টমারকে অর্ডারের সামারি (অর্ডার আইডি, ডেলিভারির সময়, মোট মূল্য) সাথে সাথে রিপ্লাই দেবে।

3. **লাইভ মেসেঞ্জার সিমুলেটর ও অ্যাডমিন ড্যাশবোর্ড:**
   - ব্রাউজারে রিয়েল-টাইম মেসেঞ্জার ইন্টারফেসে চ্যাট টেস্ট করার সুবিধা।
   - কাস্টমারদের সমস্ত অর্ডারের লাইভ তালিকা, ফিল্টারিং ও স্ট্যাটাস পরিবর্তন (Pending, Confirmed, Shipped, Delivered)।
   - কাস্টমারের ফোন নম্বরে সরাসরি **WhatsApp মেসেজ** বা কল করার লিংক।
   - এক ক্লিকে সম্পূর্ণ অর্ডার তালিকা **Excel / CSV ফরম্যাটে ডাউনলোড**।

## 🚀 কীভাবে চালু করবেন (How to Run Locally)

### অপশন ১: এক ক্লিকে চালু (Windows)
ফোল্ডারে থাকা `start-server.bat` ফাইলে ডাবল ক্লিক করুন।

### অপশন ২: টার্মিনাল বা কমান্ড প্রম্পট থেকে
```bash
node server.js
```
সার্ভার চালু হলে ব্রাউজারে প্রবেশ করুন:
👉 **http://localhost:3000**

## 🔗 ফেসবুক পেজের সাথে কানেক্ট করার নিয়ম (Meta Webhook Setup)

1. [developers.facebook.com](https://developers.facebook.com/)-এ যান এবং **Create App > Other > Business** সিলেক্ট করে একটি অ্যাপ তৈরি করুন।
2. অ্যাপ ড্যাশবোর্ড থেকে **Messenger > Set Up** এ যান এবং আপনার **Collection House** ফেসবুক পেজটি অ্যাড করুন।
3. **Webhooks** সেকশনে গিয়ে **Add Callback URL** এ ক্লিক করুন:
   - **Callback URL:** আপনার পাবলিক সার্ভার URL + `/webhook` (যেমন: `https://your-domain.com/webhook`)
   - **Verify Token:** `collection_house_webhook_token_2026` (এটি `.env` ফাইলে পরিবর্তন করতে পারেন)
4. Webhook সাবস্ক্রিপশনে `messages` এবং `messaging_postbacks` বক্সে টিক দিয়ে সাবস্ক্রাইব করুন।
5. **Generate Token** বাটনে ক্লিক করে **Page Access Token** কপি করে আপনার `.env` ফাইলে `PAGE_ACCESS_TOKEN=` এর পর পেস্ট করুন।
